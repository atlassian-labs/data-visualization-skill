# Agent instructions

This repo contains one agent skill. Start by reading [`skills/visualization/SKILL.md`](skills/visualization/SKILL.md): it is the source of truth for the style preamble, styling rules and chart selection guidance. Code for each chart type is in [`skills/visualization/references/chart-patterns.md`](skills/visualization/references/chart-patterns.md).

`.claude/skills/visualization` (Claude Code) and `.agents/skills/visualization` (Codex) are symlinks to `skills/visualization`, so edits there change the installed skill too.
